What is Aetheris?


A control panel for the Minecraft server running on your own PC. It does what Aternos does, but your server stays yours.


Aetheris has two parts:


    

  • The tray app (Aetheris.exe) runs your Minecraft server (Java), reads its log, edits its files and runs schedules. It sits in the system tray next to the clock and uses about 2 MB of RAM and 0% CPU while idle.
    • 

  • This panel is just a window onto the tray app. You can close it whenever you like and the server keeps running. Open it again from the tray icon.
    • 



Everything Aetheris changes is a normal Minecraft file in your server folder (server.properties, whitelist.json, mods/ and so on). No data is uploaded anywhere. If you stop using Aetheris, your server works exactly as before.


The tray icon: left-click opens the panel. Right-click gives Start, Stop, Restart, Open server folder and Exit. Exit always saves and stops the server first.







First-time setup


Five steps from nothing to a running server.


    

  1. Choose your server folder. On first launch, click Choose server folder on the Dashboard, or go to Settings → Server folder. Pick the folder with your server.jar. An empty folder works too.
    2. 

  2. Get server software (if the folder is empty). Open Software, choose Vanilla, Paper, Purpur or Fabric, pick a version and click Install. Not sure which? Server types explains each one.
    3. 

  3. Check Java. On Software, click Check version. The Java versions table shows which Java your Minecraft version needs.
    4. 

  4. Accept the EULA. Mojang requires every server owner to agree to the Minecraft EULA. Click I agree on the yellow banner. This writes eula=true into eula.txt.
    5. 

  5. Click Start. The first start takes longer while the world is generated. When the status turns green and says Online, you're ready. To let friends join over the internet, set up playit.gg.
    6. 



Set the server's RAM in Settings. On an old PC, 2–3 GB is a good start for a few friends, and modpacks need 4–6 GB. Leave at least 1–2 GB free for Windows.







Everyday use


    

  • Start / Stop: the big button on the Dashboard, the small one in the top bar, or the tray menu.
    • 

  • Restart: saves the world, stops the server, then starts it again. Most setting changes need one. When they do, a yellow Restart needed bar appears at the top of every page and stays until you restart.
    • 

  • Run Aetheris with Windows (Settings) plus Start the server when Aetheris opens means your server comes back by itself after the PC reboots.
    • 

  • Close the window when you're done. Minimizing works too, but closing frees the most memory.
    •

Numbers


    

  • Server RAM is how much memory the Minecraft (Java) process uses right now, measured the same way as Task Manager's “Memory” column. “of X allocated” is your maximum RAM setting. Java often uses a little more than that because of its own overhead. That's normal.
    • 

  • Server CPU is the share of your whole processor the server uses. 100% means every core is fully busy.
    • 

  • PC memory free is how much RAM Windows has left. If it gets close to zero, the PC starts swapping and everything slows down. Lower the server's RAM or close other programs.
    • 

  • The graphs cover the last few minutes while the panel is open. Aetheris doesn't record anything while the panel is closed, to keep its RAM and CPU near zero.
    •

Console


The live log of your server, plus a box to type server commands.


    

  • Type commands without the leading / (it's removed for you anyway). Press Enter to send, and ↑/↓ to go through earlier commands.
    • 

  • Click a quick-command chip to fill it in, then edit it and press Enter.
    • 

  • Search and filters show only matching lines: warnings, errors, chat or join/leave.
    • 

  • Log file downloads logs/latest.log, the full log of the current run, which is handy when asking for help.
    •

Server options (server.properties)


The main settings file of every Minecraft server. Aetheris shows the important ones as switches and explains each.


    

  • Change things, then click Save in the bar at the bottom. A small dot marks each changed option, and Discard undoes everything unsaved.
    • 

  • Most options apply after a restart. The yellow Restart bar reminds you.
    • 

  • You can edit options while the server is offline. If the server has never started, server.properties is created for you.
    • 

  • All other properties at the bottom lists every remaining line of the file, so nothing is hidden.
    •

Game rules


Game rules are switches stored inside the world that change how the game behaves, like keepInventory, mob griefing or the daylight cycle.


    

  • They aren't in server.properties. They're saved in the world's level.dat, so each world has its own.
    • 

  • They can only be read or changed while the server is online, using the /gamerule command. Aetheris runs it for you.
    • 

  • Changes apply instantly, with no restart needed, and stay saved.
    • 

  • Rules your Minecraft version doesn't have are marked “not available”. Newer versions (1.21.11 and the 26.x releases) renamed rules to snake_case, such as keep_inventory. Aetheris detects this from the server version.
    • 

  • Use Set any game rule for rules not in the list, such as spawnChunkRadius.
    • 



Popular ruleEffect


keepInventoryKeep items and XP when you die.


mobGriefingOff = creepers don't destroy blocks and endermen don't take them.


doDaylightCycleOff = time stops. Pair it with time set day for permanent day.


playersSleepingPercentagePercentage of players who must sleep to skip the night. Set 0–1 so one sleeper is enough.


doInsomniaOff = no phantoms.


randomTickSpeedCrop and tree growth speed. Default 3. High values cause lag.

Online vs offline changes


While the server is online, Aetheris uses the real commands (whitelist add, op, ban…), so changes apply instantly. While it's offline, Aetheris edits whitelist.json, ops.json and the ban files directly. For premium servers, it looks up the player's real ID (UUID) from Mojang, so the name must be a real Minecraft account. For cracked servers (online-mode off), it calculates the offline ID the same way Minecraft does.







Worlds


    

  • A server plays one world at a time: the folder named in level-name (default world). Its Nether and End live in world/DIM-1 and world/DIM1 on Vanilla, or in world_nether and world_the_end on Paper and Spigot. Aetheris handles both layouts.
    • 

  • Use this world: switches level-name to another world folder.
    • 

  • New world: picks a new name, seed and type. It's generated on the next start, and your old world is kept.
    • 

  • Reset current world: deletes the current world (all dimensions) and generates a fresh one. Make a backup first!
    • 

  • Upload a world: copy the world folder (the one containing level.dat) into the server folder, or upload it in Files, then click Use this world.
    • 



Worlds can only be changed while the server is offline, because Minecraft keeps them open while it runs.

Adding them


    

  • Drag and drop files onto the Mods page, or click Upload.
    • 

  • .jar: copied into the folder.
    • 

  • .zip of jars: every .jar inside is extracted.
    • 

  • Server pack .zip (contains a mods/ or plugins/ folder): the whole pack is extracted into your server folder, configs included.
    • 

  • .mrpack (Modrinth modpack): Aetheris downloads every server-side mod in it and applies its config overrides. It then tells you which loader and version the pack needs. Install that in Software.
    • 

  • CurseForge: choose CurseForge as the source in the browser. CurseForge only allows downloads with an API key: paste your free key from console.curseforge.com in Settings. Making mods work (Vanilla → Fabric)


Fabric, Forge and NeoForge mods are not interchangeable: a Forge mod only works on a Forge server, and so on. Choose the loader your mods (or modpack) are made for. You can install Forge or NeoForge from Software; their official installer runs for you.


A plain server.jar is Vanilla, and Vanilla ignores the mods folder. On the Mods page, click Switch to Fabric. Aetheris downloads Fabric for your exact Minecraft version (read from your server jar), and your world and settings stay. Restart, and the mods load.


Everyone needs the same mods


Mods that add things (blocks, items, mobs…) must also be installed by every player, in the same version, or they can't join. The labels show which is which: players need it, optional for players (works without it on the player's side, e.g. Lithium), server only (players don't need it, e.g. Chunky) and client only (does nothing on a server, so remove it). needs MC … means the mod was made for a different Minecraft version and will probably crash the server.


Click Make client modpack to give everyone the exact set:


    

  • .mrpack: friends import this one file into the Modrinth App, Prism Launcher or the CurseForge app. It installs the right Minecraft version, Fabric and all the mods automatically.
    • 

  • .zip: the mod files plus a “HOW TO INSTALL.txt” for manual setup.
    • 



Server-only mods and mods that are optional for players (according to Modrinth) are left out of the pack. Make a new pack whenever you add or update mods, and send it again.


Managing


The switch next to each item enables or disables it. Disabled files are renamed to .disabled and the server ignores them. Mod names and versions are read from inside each jar. Changes apply after a restart. Datapacks can also be reloaded live with the reload command.


A mod made for a different Minecraft version or loader is the #1 cause of crashes on start. If the server crashes after adding something, disable the newest file and restart.







Backups


    

  • A backup is a zip of the current world (overworld, Nether and End) saved in backups/ in your server folder.
    • 

  • Safe while running: Aetheris sends save-off and save-all flush, copies the files, then sends save-on, so the world isn't half-written in the zip.
    • 

  • Restore replaces the current world with the backup. The server must be offline. Make a fresh backup first if you might want the current world back.
    • 

  • Automatic backups (Settings) run while the server is online, every 1–24 hours. Only the newest N automatic backups are kept (files starting with auto_). Manual backups are never deleted automatically.
    • 

  • Download a backup to keep a copy on another drive or cloud storage. A backup on the same disk won't save you if the disk dies.
    • 








Schedules


Run commands automatically, either every X minutes or at a time of day.


    

  • Each schedule has one or more commands (one per line, no /).
    • 

  • Every X minutes counts from when the server started. Daily at uses this PC's clock.
    • 

  • Schedules only run while the server is online. Aetheris checks once a minute, so times can be up to a minute late.
    • 

  • Click the play button to run one immediately and test it.
    • 

  • The templates are ready-made schedules: announcements, saves, clearing dropped items and restart warnings.
    • 



Daily restarts and automatic backups are in Settings and are listed on the Schedules page too.







Software


    

  • Installed server jars lists every .jar in your server folder. Use this picks which one starts. Upload .jar adds your own (for example a Forge shim jar).
    • 

  • Install downloads Vanilla, Paper, Purpur or Fabric straight from the official sites and selects it. It applies on the next start, and your worlds aren't touched.
    • 

  • Upgrading versions: back up first. Worlds upgrade to newer versions, but you can't go back to an older version with an upgraded world.
    • 

  • Java: click Check version to see which Java the server uses. See Java versions.
    • 








Files


    

  • Browse everything in your server folder. Click a folder to open it, and a text file to edit it. In the editor, Ctrl+S saves and Tab indents.
    • 

  • Upload, download, rename, delete and create files or folders. Explorer opens the current folder in Windows.
    • 

  • Files outside the server folder can't be reached from the panel. That's on purpose, for safety.
    • 



Deleting is permanent (there's no Recycle Bin). Editing a config with a typo can stop a plugin or the server from starting. When in doubt, download a copy first.

playit.gg: let friends join


Your PC is behind your router, so people on the internet can't reach it directly. playit.gg is a free tunnel: friends connect to a playit address, and playit forwards them to the server on your PC. You don't need port forwarding or a public IP.


    

  1. Download the playit agent for Windows from playit.gg and install or run it.
    2. 

  2. The first time, it shows a claim link. Open it, log in (or create a free account) and approve the agent.
    3. 

  3. In the playit dashboard, add a tunnel of type Minecraft Java. Set the local address to 127.0.0.1 and the local port to 25565 (or whatever Server port is in Options).
    4. 

  4. playit gives you an address such as something.joinmc.link. Paste it into Settings → Public address so it shows on the Dashboard with a copy button.
    5. 

  5. Optional: in Settings, set playit program to your playit.exe and turn on Start playit with the server. Aetheris then starts the tunnel with the server, and if the tunnel closes while the server is online, starts it again within a minute (auto-reconnect).
    6. 

  6. Friends add your address in Minecraft under Multiplayer → Add Server.
    7. 



If playit is installed as a Windows service (it runs in the background on its own), leave Start playit with the server off. Aetheris notices it's already running and doesn't start a second copy.


Troubleshooting playit


    

  • The dashboard badge says playit stopped: start the agent, or turn on Start playit with the server.
    • 

  • Friends see “Can't connect”: the tunnel's local port must match Server port, and the server must be Online.
    • 

  • The address changed: update it in Settings.
    •

What Aetheris changes, and what it doesn't


Aetheris starts your server exactly as Minecraft intends. It only changes things you explicitly change.


    

  • The only extra Java arguments are your RAM (-Xms/-Xmx) and two console-encoding flags, so text shows correctly in the console. These don't affect the game.
    • 

  • Optimized JVM flags, crash auto-restart and the connection watchdog are off until you turn them on in Settings.
    • 

  • Saving options only writes the options you changed. Everything else in server.properties stays as it was.
    • 

  • Nothing is installed, switched, deleted or downloaded unless you click a button for it. The only exception is Aetheris's own automatic updates, which you can turn off.
    • 








When do changes apply? Is everything synced?


Aetheris has no separate copy of your settings. It always reads and writes the real server files, so the panel and the server are always in sync.


What you changeWhen it applies


Game rules, commands, kick/ban/op/whitelist while onlineInstantly


Server options (server.properties), Paper/Spigot options, server iconAfter a restart, and the yellow bar reminds you


Mods, plugins, datapacks, server jarAfter a restart (datapacks can also be reloaded live with reload)


RAM, Java path, JVM flagsAfter a restart


Worlds (switch, reset, new), restoring backupsOnly possible while offline; used on next start


Schedules, automation, playit, panel settingsInstantly (panel port: after restarting Aetheris)


Whitelist/ops/bans while offlineWritten to the files, so they're active as soon as the server starts


    

  • Changes made in-game (for example an op typing /whitelist add Steve or /gamerule keepInventory true) show up in Aetheris too, because it reads the same files and the live server.
    • 

  • Minecraft rewrites server.properties when it starts, adding any missing options with their defaults. That's normal.
    • 

  • Aetheris's own settings (aetheris.json) and schedules are stored only on this PC, next to Aetheris.exe. Nothing is synced to the cloud.
    • 

  • If you edit files by hand while the panel is open, reload the page (F5) to see the changes.
    •

Updating Aetheris


    

  • With Automatic updates on (Settings), Aetheris checks the latest GitHub release every 6 hours. It asks github.com which release is latest, which isn't rate-limited like the GitHub API, and adds a cache-busting value so it never gets a stale answer.
    • 

  • When a newer version exists, it's downloaded, checked (it must be a real, newer Aetheris.exe), then swapped in. The new version safely stops the old one, takes over, and starts your server again if it was running. The panel reloads by itself.
    • 

  • While the server is running, the update waits until the server is stopped, unless you click Install now in the purple bar.
    • 

  • Manual update: download Aetheris.exe from the GitHub releases page and run it. It offers to replace the running copy.
    •

Glossary




Tick / TPSThe server updates the world 20 times a second (20 TPS). Below 20, the game feels laggy.


ChunkA 16×16 block column of the world. View distance is measured in chunks.


SeedThe number that decides how a world generates. The same seed gives the same terrain.


MOTD“Message of the day”, the description in the server list.


OpOperator, a server admin.


UUIDA player's permanent ID. Names can change, but UUIDs can't.


Premium / crackedA paid, Mojang-verified account, or an unverified offline name.


JVM / heapJava, which runs the server. The heap is the RAM you allow it (max RAM).


LoaderThe software that loads mods (Fabric, Forge…) or plugins (Paper…).


DatapackA zip of Minecraft's own data files (recipes, functions, loot) that works on any server.


TunnelA forwarded connection (playit.gg) that lets the internet reach your PC.


EULAMojang's license agreement you accept to run a server.







Performance tips for old PCs


    

  1. Use Paper (or Fabric with Lithium + FerriteCore). This is the biggest single improvement.
    2. 

  2. View distance 6–8, simulation distance 4–6 in Options.
    3. 

  3. Turn on Pause when empty, so the server barely uses CPU when nobody's on.
    4. 

  4. Pre-generate the world with the Chunky plugin or mod (for example chunky radius 2000, then chunky start) while nobody's playing. Exploring new land is the heaviest thing a server does.
    5. 

  5. Set a world border so players don't generate endless new chunks.
    6. 

  6. Lower the spawn limits (Paper) and clear dropped items with a schedule.
    7. 

  7. Give the server enough RAM but not too much: 2–4 GB for small servers. Leave 1–2 GB for Windows.
    8. 

  8. Keep the optimized JVM flags on, and use a daily restart.
    9. 

  9. Put the server folder on an SSD if you have one.
    10. 

  10. Close the Aetheris window (and other programs) when you don't need them.
    11. 








Troubleshooting


ProblemFix


“Could not launch Java”Java isn't installed or isn't on PATH. Install it, or set the full path to java.exe in Settings.


UnsupportedClassVersionErrorYour Java is too old for this Minecraft version. See Java versions.


“You need to agree to the EULA”Click I agree on the Dashboard.


“Failed to bind to port”Another server (or another copy of this one) is already using that port. Stop it, or change Server port.


Server crashes right after adding a mod or pluginDisable the newest one on the Mods page and restart. Check that it matches your Minecraft version and loader.


OutOfMemoryErrorRaise Maximum RAM in Settings, or remove heavy mods.


“Can't keep up! Is the server overloaded?”A lag spike. If it happens constantly, follow the performance tips.


Friends can't connectServer Online? playit agent running? Tunnel local port = Server port? Same Minecraft version?


“Failed to verify username”A cracked player on a premium-only server. Turn off Premium accounts only, or use a premium account.


Kicked for chat / “invalid signature”Turn off Require secure chat.


Restart loops after a crashAfter 3 crashes in 10 minutes, Aetheris stops trying. Read the red lines in the console or download the log.


“A Minecraft server is already running outside Aetheris”Something else (a server started from cmd, or one left over after Aetheris was force-closed) is using the server port. Click Stop it safely (saves the world) or Force kill, then start your server normally.


Stuck on “Stopping…”Aetheris waits up to 90 seconds for the world to save. After 15 seconds, the button turns into Force stop, which ends Java and everything it started. After 90 seconds, this happens automatically.


“An older copy of Aetheris is already running”Click Yes to switch: the old copy's server is saved and stopped, the old copy closes, and the new one starts the server again.


The panel says “Connection to Aetheris lost”Aetheris was closed or crashed. Start Aetheris.exe again and the page reconnects by itself. If Aetheris ever crashes, details are saved in aetheris-crash.log next to Aetheris.exe.


Aetheris says the panel port is in useAnother program uses port 8165. Change "Port" in aetheris.json.


Settings changed but nothing happenedMost things need a restart. Use the yellow Restart now bar.







Safety & privacy


    

  • The panel only listens on 127.0.0.1, so no one on your network or the internet can open it. It also rejects requests from other websites.
    • 

  • Downloads only come from official sources: Mojang, PaperMC, Purpur, Fabric, Modrinth and GitHub.
    • 

  • The Files page can't reach anything outside your server folder.
    • 

  • Only download mods and plugins from trusted places. A jar can run any code on your PC.
    • 

  • Keep Premium accounts only on, or use a whitelist, so strangers can't join as you or as your admins.
    •
