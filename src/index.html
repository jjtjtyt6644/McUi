Changes apply instantly. Rules your Minecraft version doesn't have are marked “not available”.

Set any game rule

Stop the server to switch, reset, create or delete worlds.

Worlds

Upload a world

Unzip your world, then copy its folder (the one that contains level.dat) into the server folder, or use Files to upload it. It will show up here so you can activate it.

Backups

Backs up the current world (overworld, nether and end) into a zip. Safe while the server is running, because Aetheris pauses saving while it copies. Set up automatic backups in Settings.

Installed server jars

Install server software

Downloads come straight from the official Mojang, PaperMC, Purpur or Fabric servers. The new jar is used the next time you start the server. Your worlds aren't touched.

Java

Minecraft 1.20.5+ needs Java 21, and the newest releases may need Java 25. Older versions (1.17–1.20.4) run on Java 17. Change the Java path in Settings.
